# TU Wien, for the City of Vienna

OIB 2 building code checks for permit models.

## The publisher's own page

- [TU Wien research data, record 1](https://researchdata.tuwien.ac.at/doi/10.48436/krhhx-xyz91)
- [TU Wien research data, record 2](https://researchdata.tuwien.at/records/yh1wr-8t679)

## Files in this folder

The three folders hold the 16 IDS files from the two TU Wien research data records, unchanged, with the publisher's file names. Copied under CC BY 4.0, with credit to the authors named on the records. Some files use extensions beyond IDS 1.0, as the folder names say.

## Using these files

1. Take a file from this folder, or the current version from the publisher's page.
2. Open a file in [idsbench](https://github.com/BIMvoice/idsbench) or another IDS tool to read it, check it, and run it against an IFC model.
