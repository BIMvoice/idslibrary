## Files in this folder

`KIM-1.1.0/` holds the 54 IDS files of KIM version 1.1.0, in one folder per delivery stage and one file per discipline, with the publisher's own file names.

**These are Bane NOR's files, copied here unchanged for convenience.** All rights remain with Bane NOR. Bane NOR's page states no licence for reuse, so treat these copies as you would the originals: use them for Bane NOR projects as Bane NOR intends, and take the publisher's page as the authoritative and current source. They are not endorsed by Bane NOR as hosted here. If Bane NOR asks, they will be removed.
