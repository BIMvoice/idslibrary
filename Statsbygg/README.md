## Terms for reuse

The publisher's page states no licence or terms for reuse. Download the files from the publisher and use them as the publisher intends. Ask the publisher before republishing them. That is why this folder holds a description and a link, and no copies.

## Using these files

1. Download them from the publisher's page.
2. Open a file in [idsbench](https://github.com/BIMvoice/idsbench) or another IDS tool to read it, check it, and run it against an IFC model.

These files are in an IDS version older than 1.0. idsbench works with IDS 1.0, so they need to be updated by the publisher first.
